# Sistem Gudang DPSA

Proyek ini tidak dimulai dari nol. Awalnya ada prototipe monolith di `PT-Dharma-Putra/sistem-gudang-material`. Prototipe itu sudah punya tampilan, tapi belum punya backend dan database sungguhan. Tugas kami adalah meneruskannya. Kami memisahkan frontend dan backend, lalu menambahkan database, autentikasi, hak akses, dan alur kerja yang dipakai orang gudang sehari-hari.

Repo prototipe itu kami biarkan apa adanya sebagai arsip. Semua pengembangan sekarang ada di organisasi ini.

Organization ini dibuat supaya proyek tetap hidup walaupun orangnya berganti. Kalau kamu sekarang memegangnya, anggap ini milikmu. Ubah yang perlu diubah, hapus yang tidak terpakai, dan tulis alasannya di `docs/` supaya orang setelahmu tidak perlu menebak.

Terima kasih dan semoga sehat selalu
